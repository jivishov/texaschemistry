4. **The overlap check** in `tools/slides-kit/audits/layout.js` (RULES 3 and 11; KIT.md's audit line). The audit takes a theme argument like `walk.js` (`layout.js light|dark`, default light) and `suite.py` runs it once per theme the run asks for. On every frame of every slide, after the frame's transitions have settled (the audit already opens with reduced motion, so stages jump to their end state; keep the 100 ms wait and add a settle wait for the `.acc` compaction):
   - **DOM boxes.** Collect the visible elements of these kinds inside `.slide.current` and in `#foot`: text lines (every element whose own text nodes are visible: `p`, `li`, `td`, `th`, `h2`, `.line`, `.cell`, `.rh`, `.q`, `.ans`, `.fb`, `.tag`, `.term`, `.mean`, `.k`, `.small`, `.cap`, `.nm`, `.fm`, `.bt`, `.why`, `.big`, `.hdr`, and any other leaf with visible text), cards (`.card`, `.phase`, `.wcard`, `.item`, `.key`, `.colh`, `.cer-box`), chips and badges (`.chip`, `.badge`, `.es`, `.rail li`, `.legend>span`, `.scale span`, `.opt`), and the three footer spans. Two boxes **intersect** when their rectangles overlap by more than 2 px in both directions and neither contains the other (containment, such as a text line inside its card or a chip inside its row, is not an intersection). Skip pairs where one element is an ancestor of the other, and skip hidden, zero-size or `opacity: 0` elements and anything in `.notes`, `script`, `.timer` digits that are not running, and `.zoomed` clones. Report each intersection as `s<N>f<F>: <box A> ∩ <box B> (<px> × <px>)` with ids or classes and the overlap size.
   - **Canvas label boxes by test-time instrumentation**, without changing the runtime: with `page.addInitScript` define a setter for `window.Deck` that, when the runtime assigns the Deck object, installs a setter for its `canvasSim` property; the wrapped `canvasSim(host, spec)` replaces `spec.draw` with a function that hands the sim a proxy of the painter `g`: every `text`, `chem` and `badge` call records a **label box** (position from the call's x, y, align and size; width from `ctx.measureText` with the font the painter set, or the width `chem` returns; height the font size), and every `circle`, `rrect`, `electron` and `badge` call records a **shape box**; the boxes of the last paint are stored on the host element (for example `host.__boxes = {labels, shapes, stage}`) and cleared at the start of each paint. The audit reads them per visible `.sim` host after the frame settles (the painter paints on `set`, `resize` and each live frame, so read after the wait). Assertions per frame and host: no two label boxes intersect by more than 2 px; no label box partly intersects a shape box (a label fully inside one shape is that shape's label and is fine; a label touching or crossing a shape's edge by more than 2 px fails); both reported with the stage name, the label text and the shape kind. `D.spheres` draws through the same painter, so its symbol labels and spheres are covered. If the painter's calls cannot be wrapped reliably (say so with the reason), the fallback is a small change to `parts/shared/02-runtime.html` that makes the painter record the boxes itself; then every registered deck is rebuilt, both decks' suites re-run with the matrix off, and the md5s before and after go into the report (KIT.md's rule). Prefer the instrumentation.
   - **Live stages**: with reduced motion the painter draws one still end state; that is what this step measures. (Step 02's suite also runs the walk with motion on; the zoom audit measures after settling as today.)
   - **Gate**: a frame with any intersection fails the audit. Run the new check on 4.1 and 4.2 in the light theme. If a reference deck fails, do **not** change the deck or loosen the check: list every failing frame with its boxes in `workshop/artifacts/01/overlap-4-1-light.txt` and `overlap-4-2-light.txt`, save a cropped JPEG of up to six of them under `workshop/artifacts/01/overlap/` (at most 800 KB each), and report the count per deck; the orchestrator decides. If both pass, say so with the frame and box counts.
